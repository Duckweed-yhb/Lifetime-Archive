# Lifetime-Archive · 一生之藏

这里是我个人的内容收藏与记录库：读过的书、追过的文、看过的片、攒下的资料与笔记，都收在这一处。

### 🏛️ 关于本仓库

本仓库前身为「一生的阅读计划」，随内容扩展后更名为 **Lifetime-Archive · 一生之藏**。

当前结构从「每类一张 Excel」改为 **一张总表统管全部条目**，分类由总表里的「类别」列区分；README 里的统计与书单由脚本从总表重新生成，不再手抄。

### 🗂️ 目录结构

```
Lifetime-Archive/
├─ Lifetime-Archive_总表.xlsx   # 唯一数据源（全部条目）
├─ sync_readme.py               # 从总表刷新 README 的统计与书单
├─ README.md
├─ notes/                       # 读书笔记（按书名分目录）
├─ typeset/                     # 排版工程（LaTeX）
├─ books/  movies/              # 早期分类脚本（见下方「脚本」）
├─ study/  webnovels/
└─ .vscode/
```

### 🛠️ 脚本

| 脚本 | 状态 | 说明 |
| --- | --- | --- |
| `sync_readme.py` | 可用 | 读总表 → 重写 README 里被标记包住的「统计」与「书库快照」两段，其余文字不动 |
| `books/book_list.py` | 已停用 | 早期版本：生成 `books/一生的阅读计划.xlsx`，并回写 README 书单 |
| `movies/movie_list.py` | 已停用 | 早期版本：生成 `movies/影视记录.xlsx` |
| `study/study_material_list.py` | 已停用 | 早期版本：生成 `study/学习资料.xlsx` |
| `webnovels/webnovel_list.py` | 已停用 | 早期版本：生成 `webnovels/网文记录.xlsx` |

四个 `*_list.py` 已被总表取代，**不要直接运行**：它们各自只会生成自己那一类的表，且表里是脚本内置的旧数据，跑一次就会把已合并的旧文件重新造出来。要改数据，直接改总表，再跑 `sync_readme.py`。
