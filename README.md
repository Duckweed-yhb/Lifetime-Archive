# Lifetime-Archive · 一生之藏

这里是我个人的内容收藏与记录库：读过的书、追过的文、看过的片、攒下的资料与笔记，都收在这一处。

### 🏛️ 关于本仓库

本仓库前身为「一生的阅读计划」（A-Lifetime-Reading-Plan），最初只管理纯书单。随着内容长成书籍、网文、影视、学习资料、笔记与排版工程的混合体，于 2026-10-15 更名为 **Lifetime-Archive · 一生之藏**，并把内部按类别重新归置。

定位：把这一生值得留住的「内容」按类收好，既是清单，也是档案。

### 📁 目录结构

| 目录 | 内容 |
|---|---|
| `books/` | 一生的阅读计划.xlsx + book_list.py（书籍书单） |
| `webnovels/` | 网文记录.xlsx + webnovel_list.py（追更网文书单，含最新备份） |
| `movies/` | 影视记录.xlsx + movie_list.py（电影 / 纪录片记录） |
| `study/` | 学习资料.xlsx + study_material_list.py（时文、教辅、工具书等） |
| `notes/` | 阅读笔记：学习的逻辑 / 你杀了谁（占位） |
| `typeset/` | 时文精粹第 11 辑 LaTeX 排版工程 |
| `backup/` | 网文历史备份（归档，只保留最新一份在工作区） |
