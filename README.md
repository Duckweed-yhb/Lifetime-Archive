

# 📚 A Lifetime Reading Plan

> 以一生为尺度，用阅读构建自己的精神世界。  
> 计划始于：2026 年 2 月 13 日  
> 用代码管理阅读，让成长有迹可循。

---

## 🎯 项目简介

这是我的终身阅读计划仓库，核心是：

- **自动化书单管理**：用 Python 脚本生成/更新阅读书单
- **结构化知识沉淀**：按分类整理书籍，便于复盘和回顾
- **可追踪的成长轨迹**：记录每本书的阅读状态、时间和收获

---

## 📁 仓库结构
```
A-Lifetime-Reading-Plan/
├── README.md # 项目说明与总览
├── 阅读书单 /
│ ├── book_list.xlsx # 核心阅读书单（由脚本生成）
│ ├── book_list.csv # 书单的 CSV 格式备份
│ ├── 我的阅读书单.xlsx # 手动维护的原始书单
│ └── 阅读书单.py # Python 脚本：生成 / 更新书单
└── notes/ # 读书笔记目录（每本书对应一个笔记文件）
└── ...
```
---

## 🚀 如何使用

1.  **更新书单**：
    - 编辑 `阅读书单/我的阅读书单.xlsx`，添加/修改书籍信息
    - 运行 `阅读书单/阅读书单.py`，自动生成 `book_list.xlsx` 和 `book_list.csv`

2.  **查看书单**：
    - 直接打开 `book_list.xlsx`，查看所有书籍的分类、状态和进度
    - 或在 GitHub 上浏览本 README 中的书单展示

3.  **沉淀笔记**：
    - 每读完一本书，在 `notes/` 目录下新建笔记文件（如 `《局外人》-阿尔贝·加缪.md`）
    - 记录核心观点、个人思考和行动清单
